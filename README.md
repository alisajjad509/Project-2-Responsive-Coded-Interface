Project Title: FlashBright 
Product Description: I created an outline of an E-commerse website meant to resale varieties of flashlights to consumers. 
Intended User: Consumers looking for flashlights for personal use, emergencies, businesses, etc. 
User Goal: User should be able to conveniently navigate through the website to find what kind of flashlight they are seeking with ease, confort, and in a quick manner. Layout should be easy to understand with user friendly interface. 
Inspirational interfaces: 
Jaguarimports.com 
I like how the header menu bar includes categories and options to direct customers to more specific types of products as well as a search bar if a customer is looking for a specific item, saving them time and energy. Featured products are visible on home page. 
Amazon.com 
I love how Amazon's website is very easy to navigate. Their buttons such as their log in and cart buttons are in the top right corner where most people would expect to see them. Their top navigation bar is well structured making navigation more convenient.
Their high contrast colors on certain elements make important buttons and links visually stand out from the rest. 
 Technologies used: HTML CSS 
 Credits: Youtube Channel BroCode
 Future Improvements: Fully functional cart button and add to cart buttons applied in Javascript to total the amount of items selected and display how many items are currently in cart.
